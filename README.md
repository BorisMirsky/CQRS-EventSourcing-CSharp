# CQRS-EventSourcing-C#
Реализация паттерна CQRS на C#


Event Sourcing - архитектурный паттерн, отвечает за хранение изменений. Он работает с действиями, которые уже произошли.
Хранится не текущее состояние, а последовательность событий, которые к этому состоянию привели.


CQRS — архитектурный паттерн для разделения операций чтения и записи:

- Command side — принимает команды, меняет состояние через генерацию событий.

- Query side — подписывается на события и строит удобные проекции для чтения.


Event Sourcing и CQRS не обязательно использовать вместе, но в этом проекте они вместе.

## Агрегат (Aggregate)

**`BankAccount`** — корневая сущность, которая гарантирует бизнес-правила:
- Баланс не может стать отрицательным.
- Замороженный счёт нельзя пополнять или снимать с него.

Все изменения порождают **события**, которые сохраняются в Event Store.  
Агрегат восстанавливает своё состояние, проигрывая **историю событий**.
